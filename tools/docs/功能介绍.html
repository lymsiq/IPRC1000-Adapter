IPRC1000 遥控器适配器

把一支蓝牙语音遥控器，变成电脑上的「语音输入 + 快捷键 + 无线鼠标」。

一句话：按住遥控器上的语音键说话，文字直接进输入框；其余 20 多个键可以随意改成快捷键、媒体键或鼠标动作。

一、软件能做什么

1按住说话（核心） 按住语音键 = 按住键盘右键 Alt，松开即结束。豆包、千问、微信输入法等「按住说话」的输入法立刻可用，不用改任何设置。
2全键可改 23 个按键全部可以改：单键、组合键（如 Ctrl+V）、媒体键、F1–F12，甚至鼠标左/右键与滚轮。
3多套配置组 一台遥控器可存多套按键方案（如「办公」「剪映」「WorkBuddy」），按方块键循环切换，不用重设。
4无线鼠标模式 方向键控制光标（越推越快）、确认键=左键、info 键=右键。躺床上操作电脑不必再找鼠标。
5截图点击 把鼠标对准屏幕上任意一个图标「采集」一次，之后按一个键就能点它 —— 连软件里没有快捷键的按钮也能点。
6媒体与系统键 音量加减、静音、播放/暂停、上一曲/下一曲、切换窗口，直接映射到遥控器上。

三、四步开始用

  1. 安装本软件双击安装包 → 点「是」→ 装完可让它自动做环境部署（会装虚拟键盘驱动、虚拟声卡）。
  2. 配对遥控器按住遥控器 下+LAST 让它进入蓝牙搜索模式， 然后在 Windows「设置 → 蓝牙和其他设备 → 添加设备」里选 IPRC1000。
  3. 准备语音输入法（很多人漏这一步）本软件不含语音识别。你需要自己装一个支持 「按住说话」的语音输入法（豆包输入法 / 千问输入法 / 微信输入法等），设成默认，并把它的 语音快捷键设为 右 Alt（按住）。详见下面第五节。
  4. 试一下把光标放进任意输入框，按住语音键说话，松开看文字是否出现。

四、蓝牙搜索模式（重新配对）

什么时候需要：换了电脑、遥控器没反应、系统里找不到设备。

怎么做：同时按住 下+LAST，遥控器进入蓝牙搜索模式（此时电脑蓝牙列表才看得到它）； 配对成功后遥控器会自动退出搜索模式。

小提示：平时遥控器会休眠省电，按任意键即可唤醒；系统里显示「已配对 · 休眠中」是正常现象。

五、语音输入的前提（第一次必须做）

本软件不做语音识别。它只做两件事：① 按住语音键时，向系统发送「按住右 Alt」； ② 把遥控器收到的声音送进虚拟声卡 CABLE Input。 识别文字是输入法的工作 —— 所以必须先有一个支持「按住说话」的语音输入法。

1. 装一个语音输入法

豆包输入法、千问输入法、微信输入法等，任选其一，设为默认输入法。 它们通常都有「长按说话 / 按住说话」模式，把触发键设为 右 Alt 即可与遥控器对上。

2. 麦克风要选 CABLE Output

遥控器的声音是经虚拟声卡转给输入法的，所以输入法必须去听 CABLE Output，否则它听到的是电脑麦克风（听不到遥控器）。

输入法的设置方式你要做的事
跟随「系统默认麦克风」在软件「环境设置」里点「设为默认麦克风」（或「一键完成全部」），把系统默认录音设备设成 CABLE Output 即可。
输入法自己指定麦克风（不跟随系统）进输入法的「语音 / 听写 / 音频」设置，把麦克风手动选为 CABLE Output (VB-Audio Virtual Cable)。

3. 用这条顺序验证（30 秒）

  1. 按住语音键输入法应出现「正在聆听 / 说话中」之类的提示 → 说明按键这条路通了。
  2. 看软件面板「最近收到音频」说话时应始终 < 1 秒（绿色）→ 说明音频这条路通了。
  3. 松手看是否出字出字 = 整条链路通了；不出字但前两步都正常 = 问题在输入法（多半是麦克风选错）。

最容易错的一点：「按住有反应、也有电平，但就是不出字」—— 九成是输入法听的不是 CABLE Output。 去输入法设置里改麦克风，比反复重装软件有效。

六、常见问题

按住语音键，屏幕上冒出一串 m？
这是「遥控器被系统当成了键盘」。打开软件 → 环境设置 → 看顶部那行状态： 红色就点下面的「切换设备驱动」（需要管理员）；黄色表示遥控器在休眠，按一下唤醒再看。 切换成功后应显示绿色「不会输出任何字符」。
按了键，电脑没反应？
先看软件「按键映射」页顶部的最近按键：按遥控器时它跟着变，说明信号到了，问题在映射（可能该键没设置）； 不变则说明信号没到（遥控器休眠 / 未配对 / 需要重新进搜索模式）。
语音键按住没反应，但其他键正常？
多半是虚拟键盘驱动没装好。环境设置里看「虚拟键盘驱动」是否已就绪；没有就点「安装虚拟键盘驱动」。
按住有反应、面板也有音频，但就是不出字？
几乎都是输入法的麦克风选错了：它听的是电脑麦克风，而不是 CABLE Output。 去输入法设置里把麦克风改成 CABLE Output (VB-Audio Virtual Cable)（见第五节）。
还没有语音输入法？
本软件不含识别引擎。请先装豆包 / 千问 / 微信等任一支持「按住说话」的输入法并设为默认， 再把它的语音快捷键设为 右 Alt。
说话后输入法没识别？
确认输入法自己设成了「按住说话」，且输入框里光标在闪。软件这边只负责把「按住右 Alt」发出去，识别由输入法完成。
能装到别的盘吗？
可以：安装包.exe --dir D:\IPRC1000。也可以直接用免安装版 zip，解压到哪里都能跑。

七、适用范围与注意

场景说明
办公 / 输入法 / 写作✓ 主要用途
看视频 / 媒体控制✓ 可用
设计软件 / 剪辑✓ 可把按键映射成快捷键
带反作弊的联机游戏✗ 不建议。本程序用虚拟键盘注入按键，内核级反作弊可能判为违规

如果一定要在游戏里用：在「环境设置 → 切换设备驱动」里把遥控器还原成普通键盘，此时输入由遥控器自身发出，对反作弊而言就是一把真实键盘（但会出现上面说的 m 问题）。
