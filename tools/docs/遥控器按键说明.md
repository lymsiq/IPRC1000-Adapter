# IPRC1000 遥控器 · 按键说明

> 按键上的文字/图标 = 遥控器**实际印的**标注（界面里也是这么显示的）
> 配置组用**最底部的方块键**循环切换（右上角会提示当前组名）

---

## ⭐ 核心用法（两组都一样）

| 操作 | 效果 |
|---|---|
| **按住 🎤（语音键）** | 向系统注入**右 Alt 按住不放** → 豆包输入法进入「长按模式」开始收音；**松手即释放** |
| **按 ▭（底部方块键）** | **切换到下一配置组**（循环），不注入任何按键 |

> 语音键在**两组里都是右 Alt**，所以切换配置组不影响说话 ✓

## 怎么改

「按键映射」页 → **点某一行** → 弹出**屏幕键盘**：

1. 先点修饰键：**`Ctrl` / `Alt` / `Shift` / `Win`**（可多选）
2. 再点主键（字母/数字/F 键/方向/媒体键…）
3. 点 **「保存映射」** 立即生效

- 只点修饰键也能保存（单独注入修饰键）
- 点 **「不执行」** = 该键不注入任何按键
- 顶部有**配置组 Tab**：`+` 复制当前组新建、双击改名、`−` 删除
- **搜索框**可按 按键名 / 显示标注 / HID 值 / 当前映射 过滤
- 「导出」「导入」只影响**当前配置组**
- 「恢复默认」把**当前组**恢复为出厂映射（**全局键不随之变化**，见下）

### 全局按键：不随配置组变化的键

弹窗右上角有一个 **「全局」** 按钮，点亮后，**这个键在所有配置组里共用同一份映射**。
按键列表里会显示「全局」标记。弹窗里再点一次即可取消。

**什么时候该用**：某个键的用途跟"当前在用哪套桌面键位"无关。最典型的就是**语音键** ——
它的值由输入法决定（豆包 = 右 Alt，微信输入法 = Ctrl+Win），跟配置组没有关系。

> 语音键**已默认设为全局**。以前每个配置组各存一份，于是首页把语音键切成微信输入法后，
> 切到鼠标模式又变回右 Alt，看起来像"切换没生效"。

**注意**：
- 全局键的值存在 `keymap.json` 顶层的 `Global` 里，不在任何配置组内
- 所以「恢复默认」「导入配置」都**不会**改它 —— 要改请在弹窗里直接设
- 把某个键设为全局时，用**当前组的当前值**作为全局值；取消全局时，该值会回写到当前组

## 一个键可以干三件事：按键 / 文本 / 宏

点任意按键行后，弹窗顶部有三个页签，**同一时刻只能选一个**：

| 页签 | 这个键按下去会 | 存在哪 |
|---|---|---|
| **按键** | 发一个键或组合键（原有行为）| `keymap.json` |
| **文本** | 把预设的一段文字**粘贴**到光标处（1–10 组任选）| `macros.json` |
| **宏** | 按顺序执行：按键 / 等待 / 粘贴 / 点击 / 移动 / 拖拽 | `macros.json` |

**文本**走**剪贴板 + `Ctrl+V`**，不经过输入法 —— 中文、emoji、多行都可靠（逐字符模拟键盘会被输入法吃掉，中文根本出不来）。
粘贴完成后会把你**原来的剪贴板内容还原**。

**宏**最多 50 步，六类步骤：

| 步骤 | 填什么 |
|---|---|
| `按键` | 虚拟键码，逗号分隔（**`17,65` = Ctrl+A**），后面填按住多少毫秒再抬起 |
| `等待` | 毫秒数 |
| `粘贴` | 选一组文本（1–10）+ **粘贴键**（默认 `Ctrl+V`；终端里改成 `Ctrl+Shift+V`）|
| `点击` | **图标匹配**（按采集过的图标找，找不到就停）或 **坐标**（录制时自动记下）|
| `移动` | 把光标移到指定位置 |
| `拖拽` | 起点 → 终点（一步表达；回放时按录制时长分步移动）|

**录制**（比手填快得多，推荐）：
点「开始录制」→ **3 秒倒计时**（这段时间把鼠标移回目标窗口）→ 做一遍你的操作 → 点「停止录制」。

- 录**键盘**（含组合键）和**鼠标点击 / 拖拽**；**不录鼠标自由移动**（那是冗余数据，回放也没意义）
- 录到的步骤**追加**到列表末尾，不会覆盖你手写的步骤
- 拖拽判定：位移超过 **8 像素**才算拖拽，手抖 3~5 像素仍算点击
- 录制出的点击默认是**坐标**，想更稳就在弹窗里把它换成「图标匹配」

**失败策略**：点步骤右侧的「停 / 跳」——
`停` = 整条宏停下（**默认**）；`跳` = 跳过这一步继续。
默认是「停」：静默跳过会产生"跑完了但结果不对"，比直接停下更难查。

**导入罗技 Lua 脚本**（「导入 .lua（罗技）」按钮）：

只提取**线性序列**里的 `PressKey` / `ReleaseKey` / `PressAndReleaseKey` /
`PressAndReleaseMouseButton` / `Sleep`，并自动剥掉 `function OnEvent(...)` 和**一层**
`if event == ...` 外壳（触发条件由遥控器键决定，脚本里写的是 G 键号）。

- 参数支持**键名**（`"space"`、`"lshift"`）和 **scancode 数字**（`29` = Ctrl）
- `Sleep` 夹在按下和抬起之间时算作**按住时长**，不是独立的一步等待
- `PressAndReleaseMouseButton(1)` 没有坐标 ⇒ 在**当前光标位置**点击

**不支持**（会报错并给行号，不会静默导入）：

| 写法 | 为什么不行 |
|---|---|
| `while IsMouseButtonPressed(5) do ... end` | 按住期间持续循环（连点）——我们没有这个模型 |
| `repeat ... until not IsMouseButtonPressed(1)` | 同上（压枪）|
| `for` / 嵌套 `if` / 变量赋值 | 属于编程逻辑，不是"一串动作"|
| `MoveMouseRelative` / `MoveMouseTo` | 相对位移没有起点锚点；绝对坐标不如直接录制 |

看到"第 N 行有 `while` 块结构"的提示时，说明这份脚本是连点/压枪类，**建议用「录制」重做**。

> ⚠ **坐标点击有风险**：录制时的窗口如果没开、或换了分辨率，按坐标点下去可能点到别的东西。
> 所以播放前会校验"前台窗口是不是录制时那个"，不是就停下。
> 能换成**图标匹配**就换成图标匹配 —— 它按画面找，窗口挪了也认。

- **中断**：宏正在跑时，**按任意遥控器键**就停（不用记是哪个键触发的）
- **循环**：页签里的「执行 N 遍」—— `1` = 触发一次（默认）；`N` = 循环 N 遍；**`0` = 一直循环**，按任意遥控器键停
  - 一直循环有**10 分钟**硬上限，到点自动停（防止忘了停一直占着遥控器）
- **兜底**：总时长超过预算会自动中止，并把所有按下的键**抬起来**（不会留下卡键）
- **试运一遍**：先保存再跑，跑的是你刚改的版本

> `keymap.json` 与 `macros.json` 都在 `%APPDATA%\IPRC1000 Adapter\`。
> 绑定关系存在 `keymap.json` 里（负数 `-1001` 起），所以**导出一个配置组会带上它引用的文本/宏**。
