# IPRC1000 遥控器 · 按键说明

> 按键上的文字/图标 = 遥控器**实际印的**标注（界面里也是这么显示的）
> 配置组用**最底部的方块键**循环切换（右上角会提示当前组名）

---

## ⭐ 核心用法（两组都一样）

| 操作 | 效果 |
|---|---|
| **按住 🎤（语音键）** | 向系统注入**右 Alt 按住不放** → 豆包输入法进入「长按模式」开始收音；**松手即释放** |
| **按 ▭（底部方块键）** | **切换到下一配置组**（循环），不注入任何按键 |

> 语音键在**两组里都是右 Alt**，所以切换配置组不影响说话 ✓

| `⏯` | **播放/暂停** | 媒体控制 |

## 第二组：WorkBuddy 快捷键

> 照 WorkBuddy 的快捷键表映射；mac 的 `Cmd` 在 Windows 上对应 `Ctrl`

| 遥控器键 | 注入 | WorkBuddy 动作 |
|---|---|---|
| `pwr` | **Ctrl+Shift+W** | 关闭当前页 |
| `back` | **Ctrl+P** | 打开文件搜索 |
| `menu` | **Ctrl+O** | 全局搜索 |
| `exit` | **Esc** | 停止生成 |
| `info` | — | **不映射**（见下方「关于 info」）|
| `ok` | **enter** | 发送消息 |
| `▲` `▼` `‹` `›` | **↑ ↓ ← →** | 方向键（两组一致，只管光标）|
| `♡` | **Ctrl+I** | 打开计划面板 |
| 🎤 | **右 Alt** | ★ 语音输入（**不动**）|
| 👤 | **Ctrl+R** | 聚焦区域 |
| `⏯` | **F12** | 进入终端会话 |
| `▶▶` | **Ctrl+B** | 切换到面板 |
| `◀◀` | **Ctrl+Shift+B** | 切换右面板 |
| `ch▲` | **Ctrl+[** | 上一个任务 |
| `ch▼` | **Ctrl+]** | 下一个任务 |
| `vol+` / `vol−` | **音量 + / −** | 系统音量 |
| 🔇 | **静音** | 系统静音 |
| `last` | **Shift+Ctrl+W** | 唤起快速输入窗口 |
| `▭` | — | **固定：切换配置组** |

> 两个组的**频道键分工不同**，是按各自场景定的：
> 组1（Windows 日常）频道键 = **PgUp/PgDn 翻页**（日常里翻页更实用）
> 组2（WorkBuddy）频道键 = **Ctrl+[ / Ctrl+] 切任务**（WorkBuddy 的核心导航）

> WorkBuddy 还有几个遥控器没占用的快捷键（`Ctrl+N` 运行开发服务器、`Ctrl+P` 文件搜索、
> `Enter` 发送、`Ctrl+W` 重新加载、`/` 唤起斜杠命令、`P` 唤起选择器等）——
> 想用哪个直接点「按键映射」里对应那一行，在屏幕键盘上选即可 ✓

> **`info`（信息键）**
>
> - **第一组** = `Ctrl+enter`
> - **第二组** = 不映射
>
> 为什么第二组留空：试过 `/`、`Alt+Enter`、`Ctrl+Enter`，在 WorkBuddy 里都**无感**
> （需要先点进输入框，或该组合键本身没绑定）。留空比留一个按下去没反应的键更清楚。
>
> ⚠ **务必区分「映射没生效」和「这个组合键本身没功能」**：
> `Ctrl+Enter` 这类组合键在**大多数程序里本来就没有绑定动作**，而且要先点进一个输入框才有效。
> 所以按下去"没反应"**不等于**映射没生效。想确认程序有没有读到你的配置，跑一次映射自检：
>
> ```powershell
> & "IPRC1000 Adapter.exe" --map-dump "$env:TEMP\map.txt"; notepad "$env:TEMP\map.txt"
> ```
>
> 看 `info` 那一行：`实际注入` 与 `界面显示` 两列一致 = 映射已生效 ✓。
> 想验证注入链路本身，用**一定有反应**的键：`pwr`（Win+L 锁屏）、`menu`（右键菜单）。

## 怎么改

「按键映射」页 → **点某一行** → 弹出**屏幕键盘**：

1. 先点修饰键：**`Ctrl` / `Alt` / `Shift` / `Win`**（可多选）
2. 再点主键（字母/数字/F 键/方向/媒体键…）
3. 点 **「保存映射」** 立即生效

- 只点修饰键也能保存（单独注入修饰键）
- 点 **「不执行」** = 该键不注入任何按键
- 顶部有**配置组 Tab**：`+` 复制当前组新建、双击改名、`−` 删除
- **搜索框**可按 按键名 / 显示标注 / HID 值 / 当前映射 过滤
- 「导出」「导入」只影响**当前配置组**
- 「恢复默认」把**当前组**恢复为出厂映射
