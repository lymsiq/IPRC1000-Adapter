# IPRC1000 原生版 · 标准作业程序（SOP）

> 适用版本：**v0.4.37**（2026-11-06）
> 对应仓库：`iprc1000_native/`（Rust）
> 本文覆盖：产品介绍、两个发行版的分工、安装、功能支持矩阵、命令行工具、排障、已知边界。

---

## 1. 这是什么

把 **Verizon FiOS IPTV 遥控器（型号 IPRC1000）** 当作 PC 的**可编程输入设备**：

- **按键**：遥控器的 23 个键 → 任意键盘按键 / 组合键 / 宏 / 文本 / **启动一个程序**
- **语音**：遥控器麦克风 → 虚拟声卡 → 豆包或微信输入法（不说话时完全不占 CPU）
- **零 WebView**：不依赖 WebView2/浏览器，界面自绘

### 1.1 它到底是什么设备（别买错、别写错）

| 项 | 事实 |
|---|---|
| 正式名称 | **Verizon FiOS IPTV Bluetooth Remote**（美国 Verizon 电视盒 IPSTB1200 的配件） |
| 型号 | **IPRC1000**（主板丝印 IPRC1000；外壳背面左下 `RC3602301/02BR` + 蓝牙 MAC） |
| 芯片方案 | 博通 **BCM20734**（Bluetooth Smart 双模 + 红外，单芯片） |
| 连接 | **蓝牙 + 红外双模**；本项目只用蓝牙 |
| 供电 | **4 节 7 号(AAA) 电池，必须 4 节都装上**（红外 2 节 + 蓝牙 2 节，缺一不可） |
| 麦克风 | 机身顶部**双面拾音**麦（这就是语音功能的来源） |
| 重量 | 约 89.3 g |
| USB 识别 | `VID_0A5C` / `PID_8502`（0A5C = 博通；这也是为什么 Linux 侧要放 `Vendor_0a5c_Product_8502.kl`） |

**配对 / 复位（硬件操作）**

- 首次配对：长按右上角 **PWR**，等方形指示灯**蓝灯闪烁** → 在 Windows 蓝牙里添加设备。
- 恢复配对状态：**同时按「上一频道(last)」+「下方向键」**，即可回到可配对状态。

> 采购提示：市面同名"IPTV 遥控器"很多，认 **IPRC1000 / BCM20734 / Verizon FiOS** 三个关键词，
> 否则按键表与语音链路都对不上（本项目的 23 键表就是按这只遥控的丝印做的）。

## 2. 两个发行版（同一套配置，按机器选）

| | 完整版 | Win32 版 |
|---|---|---|
| 包名 | `IPRC1000_Native_v<ver>.zip` / `IPRC1000_Native_Setup_v<ver>.exe` | `IPRC1000_Win32_v<ver>.zip` |
| 程序名 | `IPRC1000-Native.exe` | `IPRC1000.exe` |
| 界面技术 | egui + **OpenGL** | 纯 **GDI**（零显卡依赖） |
| exe 体积 / 内存 | 5.6 MB / 约 110 MB | 1.2 MB / 约 20 MB |
| 适用 | 显卡驱动正常的机器 | 无显卡驱动、远程桌面、老集显 |
| 安装方式 | 安装器 / 解压 + `一键安装.cmd` | 解压即用 |

**选择原则**：装过一次就按实际表现定——
完整版在无 OpenGL 的机器上会自动降级到 Win32 界面（不黑屏、不闪退），
但二进制里仍带 GL 代码。若客户机长期无显卡驱动，直接用 Win32 包更省资源。

两个版本**共用** `<应用目录>\data\` 下的同一份配置，换版本不用重配。

## 4. 安装步骤

### 4.1 完整版（推荐走安装器）

1. 运行 `IPRC1000_Native_Setup_v<ver>.exe`（或解压 zip 后右键**以管理员身份运行** `一键安装.cmd`）。
2. 安装器会依次：装虚拟声卡 → 装虚拟键盘驱动 → 改造遥控器（去掉"键盘"身份）→ 设默认麦克风。
3. 启动 `IPRC1000-Native.exe`，进入「环境与安装」页确认四项全绿。
4. 若某项显示 ⚠，点「一键修复」——缺什么补什么，可能弹 UAC。

### 4.2 Win32 版（解压即用）

1. 解压到任意目录（建议 `D:\IPRC1000-Win32`，**不要**只把 exe 单独拿出来——
   同目录的 `WinUHid.dll`、`assets\` 是运行必需）。
2. 双击 `IPRC1000.exe`。
3. 顶部状态条应显示 `声卡 ✓ 麦克风 ✓ 键盘驱动 ✓ 遥控器 ✓`；
   有 ⚠ 就点「一键修复」。

### 4.3 首次必做：遥控器改造

不改的话，按遥控器会**同时打出字母**（它被系统当作键盘）。
判据：设备管理器里该设备不再是 `键盘`，而是 `HID-compliant device`。

改造方式（任选）：
- 安装器/`一键安装.cmd`（自动）
- 界面「一键修复」
- Win32 版顶部的「一键修复」

## 6. 常用操作

### 6.1 把某个键改成"打开程序"

**完整版**：「按键映射」页 → 目标行点「**程序**」→ 选 exe → 该键即变为启动键。
显示为 `打开 微信`。

**Win32 版**：选中一行 → 顶部「**绑定程序**」→ 选 exe。

**命令行装配**（远程/批量）：

```bat
IPRC1000-Native.exe --bind-program favorite "D:\Program Files\Tencent\WeChat\WeChat.exe"
```

### 6.2 查某个键到底绑了什么

```bat
IPRC1000-Native.exe --check-key 08
```

输出示例：

```
usage   = 0x08
id      = favorite   name = ♡ 收藏
绑定串  = "-2002"
action  = Some(-2002)   （后端「打开程序」读的就是这个）
vks     = []
=> 按下会执行：打开 WorkBuddy
```

判读：
- `action` 为 `None` 且绑定串是负数 → 动作没落到运行时（旧版本 bug，v0.4.31 已修）
- `绑定串` 为空、`vks` 为空 → 该键未绑定（会按出厂默认）

### 6.3 测试某个快捷方式

```bat
IPRC1000-Native.exe --launch-shortcut 2
```

## 7. 命令行工具（全部）

> ⚠ 本程序是 GUI 子系统，PowerShell 直接调用抓不到输出。要读输出请用：
> `.\IPRC1000-Native.exe --check-key 08 2>&1 | cat`（或 bash / cmd 重定向）

| 参数 | 作用 |
|---|---|
| `--install` | 全量安装（声卡 + 驱动 + 遥控器改造 + 默认麦克风） |
| `--repair` | 只做检查与修复（等价于界面的「一键修复」） |
| `--diag` | 打印模块/线程/内存概况后退出 |
| `--audio` | 音频链路自检 |
| `--check-key <hex>` | 查某个 usage 的绑定串 / action / vks |
| `--bind-program <id> <path>` | 绑定"按下打开某程序"（等价于点「程序」按钮） |
| `--hid-probe` | **按键链路诊断**：枚举遥控器 HID 接口并逐个试打开。会分别报"全系统 HID 接口数"和"匹配遥控器的接口数"，用来区分「没唤醒」和「有接口但打不开」 |
| `--launch-shortcut <n>` | 直接触发第 n 个快捷方式（验证用） |
| `--make-shortcut` | 创建桌面快捷方式 |
| `--uninstall` | 卸载（配合 `--yes` 免交互） |

## 8. 配置与日志

位置：**应用目录下**（与 exe 同一层，装在哪就在哪）

```text
<应用目录>\
├── IPRC1000-Native.exe
├── WinUHid.dll / assets\
├── data\      ← 配置
└── logs\      ← 日志
```

> 若应用目录不可写（例如装在 `Program Files`），自动回退到
> `%APPDATA%\IPRC1000 Adapter\`（配置仍放 `data\`、日志放 `logs\`）。
> 旧版本把配置放在 `%APPDATA%`，升级后**首次启动会自动迁移**，旧文件保留不删。

| 文件 | 内容 |
|---|---|
| `native.json` | **主配置**：输入法、触发方式、日志开关、各配置组的绑定表 |
| `shortcuts.json` | 「打开程序」表（编号 → 名称/路径/参数） |
| `macros.json` / `native-macros.json` | 宏定义 |
| `native-text.json` | 文本槽内容 |
| `keymap.json` | 键位覆盖（兼容旧格式） |
| `logs\native.log` | 运行日志（**排障先看这个**） |
| `bridge.log` / `bridge-stats.json` | 语音桥统计 |
| `mouse.json` | 鼠标模式参数 |

**绑定值编码**（改配置时需要知道）：

| 值 | 含义 |
|---|---|
| `17,65` | VK 序列（Ctrl + A） |
| `-1` … `-6` | 鼠标动作 |
| `-1001` … `-1010` | 文本槽 1–10 |
| `-1101` … `-1999` | 宏 1–899 |
| `-2001` … `-2999` | **打开程序**（快捷方式 1–999） |
| 空串 | 未设置（走出厂默认） |

**备份/迁移**：整个 `IPRC1000 Adapter` 目录拷走即可（不含驱动与声卡，需在新机重装）。

## 8.5 按键链路：五层排障表

按键从遥控器到应用要过五层，**断在哪一层，症状完全不同**，别一上来就重装驱动。

| 层 | 判据 | 怎么看 | 断了的症状 |
|---|---|---|---|
| ① 蓝牙链路 | 父节点 `BTHENUM\DEV_<MAC>` Present=True | 设备管理器 | 完全无反应，日志也没有 `[HID]` |
| ② HID 接口枚举 | `--hid-probe` 的"匹配遥控器" > 0 | 命令行 | `[HID] 暂未发现遥控器接口` 反复出现 |
| ③ 句柄打开 | `bridge-stats.json` 的 `hidOpen` > 0 | 看统计文件 | `[HID] 打开失败 err=…` |
| ④ 报告解析 | `hidDirect` > 0（HID 直读读到的条数） | 看统计文件 | 打开了但计数不动 = 解码/上报问题 |
| ⑤ 映射注入 | `native.log` 出现 `[KEY]`；`keyEvents` 增长 | 看日志 | 有报告无 `[KEY]` = 键位没绑（`--check-key`） |

> **界面右上角的三态**（0.4.37 起）分别对应不同层：
> · `● 遥控器在线` = 30 秒内真的收到过按键（第 ④ 层通了）
> · `◐ 已连接，按键通道未就绪` = 链路在动但一个按键都没收到（第 ②③④ 层之一断了）
> · `○ 遥控器休眠` = 连链路事件都没有（第 ① 层）
>
> 早期版本只有"在线/休眠"两态，判据是"30 秒内有没有任意蓝牙事件"——
> 信令保活就能把它刷绿，于是"显示在线、按键全无"这类故障被藏住。

### 8.5.1 为什么"改造遥控器"还需要 HID 消费者

改造是把 HID 集合节点绑成 raw（`input.inf / HID_Raw_Inst.NT`），目的是让系统不再把按键当键盘。
但 raw 之后就**没有任何客户端读输入报告**了，Windows 蓝牙 HID 便不再建立中断通道
（L2CAP PSM 0x0013）；遥控器没地方投递按键，4 秒后链路超时断开重连，无限循环。

所以 0.4.36 起程序自己当那个消费者（`hid_reader`）。**改造 + 消费者**缺一不可。

## 9. 排障

| 现象 | 先查 | 处理 |
|---|---|---|
| 按遥控器没反应 | `--check-key <hex>` | `action`/`vks` 都空 → 未绑定；有值但仍无反应 → 看 `native.log` 有无 `[INJ]` 行 |
| 按遥控器打出字母 | 设备管理器 | 遥控器还是"键盘" → 跑「一键修复」 |
| 日志有 `未找到 WinUHid.dll` | 程序目录 | exe 同目录缺 `WinUHid.dll`（从 zip 解压完整目录） |
| 日志有"设备槽位被占用" | 进程列表 | 有重复实例/上次异常退出 → 重启电脑 |
| 语音没声音 | 默认输入设备 | 应为 `CABLE Output`；点「一键修复」 |
| 语音按键不出候选框 | 「输入法」页 | 豆包↔微信输入法切换；微信输入法还需把**系统默认输入法**也切成微信 |
| 界面打不开（完整版） | `native.log` | 无 OpenGL 时自动切 Win32 界面；仍不行改用 Win32 包 |
| 装了却提示"声卡未安装" | 是否刚启动就点修复 | v0.4.31 起已在线程内初始化 COM；老版本重启后再试 |

## 10. 已知边界（不承诺的能力）

| 项 | 说明 |
|---|---|
| 语音首包延迟 | **300–500 ms**，来自遥控器固件，软件侧无法消除 |
| 键注入延迟 | 15–20 ms |
| 媒体键（音量/静音） | 受虚拟 HID 报告描述符限制（仅键盘页），可能无效 |
| 语音键改键 | 不支持，由输入法决定（全局语义，刻意设计） |
| 多实例 | 不支持（两个实例会互相停掉彼此的 ETW 会话） |
| 宏播放中按遥控器 | 任意键 = 停止播放（防跑飞） |
| 无显卡驱动 | 完整版会降级到 Win32 界面；长期使用建议直接用 Win32 包 |
